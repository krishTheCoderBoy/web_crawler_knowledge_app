How does Rust ownership prevent memory bugs?

Rust's ownership system ensures that each value has a single owner at a time. When the owner goes out of scope, the value is automatically dropped — eliminating use-after-free and double-free bugs without a garbage collector. The borrow checker enforces these rules entirely at compile time.
